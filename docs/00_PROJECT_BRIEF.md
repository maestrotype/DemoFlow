Однострочное описание проекта
DemoFlow — инструмент, который позволяет быстро превращать сырые видео/скринкасты в профессиональные продающие демо-видео с аннотациями (стрелки, выделения, текст, зум), AI-подсказками и озвучкой.
Главная ценность
"Загрузи скриншот/видео → получи готовое продающее демо за 5–10 минут"
Цели проекта

Для себя — быстро делать демо-видео для своих продуктов на маркетплейсах.
Для продажи — продавать как готовое приложение/шаблон (Gumroad, Envato и т.д.).

Текущий стек

Frontend: Angular 20+ (Standalone Components, Signals-first, Feature-Sliced Design)
Backend: NestJS (Clean Architecture)
БД: PostgreSQL + Prisma ORM
AI: Локальные модели (Qwen3-VL-30B, Qwen3-Coder-30B и др.) через Ollama / LM Studio
Видео обработка: FFmpeg + Puppeteer (рендер сцен)
Хранение: Cloudflare R2 (или локально на dev)
