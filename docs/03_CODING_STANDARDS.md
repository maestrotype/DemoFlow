04_TASK_MANAGEMENT — Как работать с задачами (универсальная версия)
Версия: 1.1.0
Дата: 2026-06-30
Этот документ создан специально для работы с разными LLM (Qwen3-Coder-30B, Qwen3-Next, Claude Sonnet, DeepSeek-R1, Gemma-4 и т.д.).

Общий подход


Все крупные задачи всегда разбиваем на маленькие подзадачи (1–3 файла максимум за раз).
Перед началом работы LLM должна прочитать ключевые документы.
Указываем, какая модель сейчас используется, чтобы можно было адаптировать стиль и глубину ответа.

Рекомендации в зависимости от модели


Qwen3-Coder-30B → самый строгий и точный. Хорошо работает с чёткими инструкциями. Лучше всего для рефакторинга и написания компонентов.
Qwen3-Next → более креативный, быстрее пишет. Можно давать чуть больше свободы.
Claude Sonnet → отлично понимает архитектуру, хорошо пишет большие связные куски. Можно давать задачи чуть крупнее.
DeepSeek-R1 / Gemma-4 → использовать для генерации промптов, тестов, документации.

Если переключаешь модель — просто укажи её в начале задачи.

Правила для всех моделей


Всегда сначала читай ключевые документы перед кодом.
Предлагай план из 3–6 подзадач перед началом написания кода.
Делай одну подзадачу за раз.
После выполнения показывай:
Какие файлы изменил
Что теперь работает
Что нужно проверить дальше
